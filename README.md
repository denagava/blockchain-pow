# blockchain-pow

[![CI](https://github.com/denagava/blockchain-pow/actions/workflows/ci.yml/badge.svg)](https://github.com/denagava/blockchain-pow/actions/workflows/ci.yml)
![Go](https://img.shields.io/badge/Go-1.23-00ADD8?logo=go)

Учебная реализация блокчейна с **proof-of-work** на Go: майнинг блоков, проверка целостности цепочки, сохранение на диск и REST API. Только стандартная библиотека.

## Как устроено

- Блок хранит индекс, время, данные, хеш предыдущего блока, nonce и свой хеш **SHA-256**.
- **Proof-of-work:** майнер перебирает nonce, пока хеш не начнётся с N нулей (`-difficulty`, по умолчанию 4).
- **Валидация:** для каждого блока проверяется, что хеш соответствует содержимому, ссылается на предыдущий блок и удовлетворяет сложности. Изменение данных в любом блоке ломает цепочку.
- **Конкурентный майнинг:** поиск nonce идёт без блокировки, а добавление блока под мьютексом. Если пока шёл майнинг, цепочку уже продлили, блок перемайнивается на новую вершину. Цепочка остаётся консистентной при любом числе параллельных запросов.
- **Отмена:** майнинг останавливается по таймауту или при обрыве запроса клиентом (`context`).
- **Хранение:** цепочка пишется в JSON атомарно (temp + rename). При загрузке она целиком валидируется, повреждённый файл не будет молча принят.

## Запуск

```bash
go run . -addr :8080 -difficulty 4 -data blockchain.json
```

## API

```bash
# Добыть блок
curl -X POST localhost:8080/mine -d '{"data": "Alice -> Bob: 10"}'
# {"index":1,"timestamp":"...","data":"Alice -> Bob: 10","prev_hash":"...","hash":"0000a3f1...","nonce":48213}

# Вся цепочка
curl localhost:8080/blocks

# Проверка целостности
curl localhost:8080/validate
# {"is_valid":true}
```

## Тесты

```bash
go test -race ./...
```

- добытый блок удовлетворяет сложности и связан с предыдущим;
- подмена данных в блоке обнаруживается валидацией;
- отклоняются блоки без PoW и блоки, ссылающиеся не на вершину;
- 8 параллельных майнеров дают корректную цепочку из 9 блоков;
- майнинг прерывается по контексту;
- сохранение и загрузка с проверкой.

## Структура

```
main.go    HTTP API и graceful shutdown
```
